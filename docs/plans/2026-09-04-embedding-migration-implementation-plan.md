# Embedding Migration (Phase 1: measure, gated) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Source spec:** `docs/specs/2026-09-04-embedding-migration-design.md` (commit SHA: `5d1ff5d`)

**Goal:** Make the server and the benchmark harness able to embed through a TEI-served model end to end, run three candidate arms (SciFact bge-base, SciFact bge-small, NFCorpus bge-base) against the preserved nomic runs, and record a non-inferiority gate verdict.

**Architecture:** `EmbeddingService` moves from Ollama's `/api/embed` to the OpenAI-compatible `/v1/embeddings` that both backends serve, builds its request URI from its own per-model base URL (`EmbeddingServiceOptions.Models`, bound from `Embeddings__Models__N__*`), and guards model identity through TEI's `/info` before recording the dimension. `ingest.py` gains the same route, a backend URL, an explicit chunk-window override and provenance fields in its stats sidecar. Compose gains a profile-gated `tei-embed` service and templated api/worker embedding env. The arms then run per spec §6 and are scored with `report.py --baseline`.

**Tech stack:** .NET 10 / C# (`Iverson.Embeddings` + xunit 2.9.3, FluentAssertions 7.0.0, NSubstitute 5.3.0), Python 3.14 (`ingest.py`, `report.py` with `ir_measures` 0.4.3 / `scipy` 1.18.1 via `PYTHONPATH`), Docker Compose 2.40.3, TEI `cpu-1.8`, Qdrant 1.18.2, Ollama (nomic baseline only).

## Global Constraints

Copied from the spec; every task must hold to them.

- **Fail loud (spec §4).** Probe failure leaves the service uninitialised (unchanged). An identity mismatch throws naming the configured and served ids **and re-throws on every later `EnsureInitializedAsync`**: the guard runs inside the init lock between the probe call and the `_dimension` assignment, never after it (spec §3.2, S6). A TEI 413 surfaces as a failed embed, never a truncated vector. A model absent from `Models` falls back to the global base URL.
- **One `/info` request per successful initialisation.** `/info` 200 with `model_id` ≠ `ModelId` (ordinal) throws; 404 (Ollama) or 200 without `model_id` is a no-op.
- **Prefix rows (spec §3.3):** `BAAI/bge-base-en-v1.5` and `BAAI/bge-small-en-v1.5` are both exactly `("", "Represent this sentence for searching relevant passages: ")`; the table stays ordinal-keyed; the family rule (id before the first `:`) is untouched. `ingest-contract.json` is regenerated by `IngestContractTests`, never edited by hand.
- **Compose (spec §3.4):** image `ghcr.io/huggingface/text-embeddings-inference:cpu-1.8`, `profiles: ["tei"]`, `--auto-truncate` mandatory, port `8091:80`, named volume `tei_models` (never under `/tmp`). Env names exactly `Embeddings__Models__0__Name=${EMBED_MODEL_ID:-BAAI/bge-base-en-v1.5}`, `Embeddings__Models__0__BaseUrl=http://tei-embed:80`, `Embeddings__ModelId=${BENCH_EMBED_MODEL:-nomic-embed-text}` on both `iverson-api` and `iverson-worker`.
- **Window (spec §3.5, §6.1):** every candidate arm ingests with `--chunk-max-chars 512 --chunk-step 448`. The effective `(max_chars, step)` is passed explicitly into `ingest_document`, which uses it for both the chunker and the reuse gate; the module globals `MAX_CHARS`/`STEP` are never rebound; `_verify_algorithm_goldens` keeps calling `split_into_chunks` with no arguments; `word_boundary_lookback` stays 50 and is not a flag.
- **Statistics (spec §6.4):** `report.py --baseline`, never `--pair`. Holm m = 2 on SciFact (M1, M2 in one invocation), m = 1 on NFCorpus. `PERMUTATION_SEED`, resamples and `HOLM_ALPHA` unchanged.
- **Gate (spec §7):** SciFact `chunks` only. A candidate passes when the 95 % CI lower bound of its nDCG@10 delta against M0 is above **−0.02** AND the 95 % CI lower bound of its R@50 delta is above **−0.02**. N1 vs N0 and every `.similar` delta are reported, not gated. The verdict goes to `docs/plans/2026-09-GATE-embedding-migration.md` with the compare blocks quoted verbatim.
- **Box discipline (spec §6.3):** nothing else runs on the box during an arm; existing run directories under `~/repositories/iverson-benchmark-corpora/` are read-only evidence — the arms write only to **new** run and snapshot directories; the box is left on the SciFact nomic baseline (5,183 / 19,967 points, API defaults) at the end.
- **Untouched:** `IEmbeddingService`, `EmbedDocumentAsync`/`EmbedQueryAsync`, `EnrichmentService`, the schema-registration guard, all five clients, Helm (Phase 2).
- Tests are written to fail against a specific named mutation.

```csharp
    private sealed class FakeHttpMessageHandler(
        HttpResponseMessage embedResponse,
        HttpResponseMessage? infoResponse = null) : HttpMessageHandler
    {
        public HttpRequestMessage? LastRequest     { get; private set; }   // /v1/embeddings requests only
        public string?             LastRequestBody { get; private set; }
        public int                 InfoCalls;

        protected override async Task<HttpResponseMessage> SendAsync(
            HttpRequestMessage request,
            CancellationToken ct)
        {
            if (request.RequestUri!.AbsolutePath == "/info")
            {
                Interlocked.Increment(ref InfoCalls);
                return infoResponse is null
                    ? new HttpResponseMessage(HttpStatusCode.NotFound)   // Ollama's answer
                    : await CopyAsync(infoResponse, ct);
            }

            LastRequest     = request;
            LastRequestBody = request.Content is not null
                ? await request.Content.ReadAsStringAsync(ct)
                : null;
            return await CopyAsync(embedResponse, ct);
        }
    }

    // A fresh HttpResponseMessage per call: EnsureInitializedAsync now issues two requests and the
    // service reads each response's content stream once.
    private static async Task<HttpResponseMessage> CopyAsync(HttpResponseMessage source, CancellationToken ct) =>
        new(source.StatusCode)
        {
            Content = new StringContent(
                await source.Content.ReadAsStringAsync(ct), Encoding.UTF8, "application/json")
        };

    // The OpenAI-compatible shape both Ollama and TEI serve at /v1/embeddings.
    private static HttpResponseMessage SuccessResponse(float[] embedding) =>
        new(HttpStatusCode.OK)
        {
            Content = new StringContent(
                $$$"""{"object":"list","data":[{"object":"embedding","index":0,"embedding":[{{{string.Join(",", embedding)}}}]}],"model":"x","usage":{"prompt_tokens":1,"total_tokens":1}}""",
                Encoding.UTF8,
                "application/json")
        };

    private static HttpResponseMessage InfoResponse(string modelId) =>
        new(HttpStatusCode.OK)
        {
            Content = new StringContent(
                $$"""{"model_id":"{{modelId}}","max_input_length":512,"auto_truncate":true}""",
                Encoding.UTF8,
                "application/json")
        };

    private sealed class CountingHttpMessageHandler(HttpResponseMessage response) : HttpMessageHandler
    {
        public int CallCount;   // /v1/embeddings requests only: "probe once per lifetime", not "one HTTP call"

        protected override async Task<HttpResponseMessage> SendAsync(
            HttpRequestMessage request,
            CancellationToken ct)
        {
            if (request.RequestUri!.AbsolutePath == "/info")
                return new HttpResponseMessage(HttpStatusCode.NotFound);
            Interlocked.Increment(ref CallCount);
            await Task.Delay(20, ct); // widen the race window for concurrency test
            return await CopyAsync(response, ct);
        }
    }
```
