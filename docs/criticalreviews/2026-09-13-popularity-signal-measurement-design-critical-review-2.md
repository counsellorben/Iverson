## 2. Literal-wrongness findings

### 2.1 Nothing between Step 1's code change and Step 3's first `Signals`-configured boot re-registers the schema, so that boot hits the same `?? throw` crash-loop fix 5 removed from Step 0

**Description.** Fix 5 correctly removed `Signals` from Step 0 and stated the constraint as "Configure `Signals` from Step 2 onward." But the registry the validator reads is not a function of the LoadTest source tree — it is a Postgres table loaded at boot by `SchemaRegistry.LoadAsync()`, written only when a LoadTest command in the `needsTenantAndSchema` set calls `SchemaRegistrar.RegisterAllAsync`. Walking the spec's own order: Step 0 runs `benchmark-query` and registers `BenchmarkDocument` **as it exists before Step 1**, i.e. without `Citations`. Step 1 edits the LoadTest entity source and prescribes two verification checks, no run. Step 2 is a Python script against Qdrant that never touches the api. Step 3 then restarts the api **with `Signals__0__ParentType = BenchmarkDocument` and `Relation = Citations` set**, and only afterwards runs `benchmark-query`. At that boot, `BenchmarkDocument` is registered (so the warn-and-skip branch is not taken) and its persisted descriptor has no `Citations` relation, so `ValidateAtStartup` reaches `parentSchema.Relations.FirstOrDefault(…) ?? throw` and the process dies before `app.Run()`. With `restart: unless-stopped` that is a crash-loop, and the `RegisterSchema` RPC that would fix it is served by the process that will not start — the exact deadlock fix 5 documents, relocated from Step 0 to Step 3. Both Step 3 boots (control and treatment) hit it, so Phase 2 produces no arm at all.

**Evidence (file:line).** `Iverson.Server/Iverson.Api/Grpc/PopularitySignalOptions.cs:104-108` (`?? throw new InvalidOperationException("'{Relation}' is not a relation on '{ParentType}'")`); `:87-97` (the warn-and-skip branch, reachable only when the ParentType is **un**registered); `Iverson.Server/Iverson.Api/Program.cs:446-449` (`await schemaRegistry.LoadAsync();` then `ValidateAtStartup(…)`), `:550` (`app.Run();`); `Iverson.Server/docker-compose.yml` `iverson-api` `restart: unless-stopped`.
